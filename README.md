Code and resources for Helping Task Pilot Study, Kwan - Shin - Zavlis - Selai - Moutoussis

Here we present two classes of models, to understand the Help-seeker - Helper interactions using the 'Helping Task', developed by Taylor Kwan, Caroline Selai, Jae Shin, Orestis Zavlis, and Caroline Selai, also in collaboration with Giles Story.

Here we provide the data collected, including Helping Task Data, Participant Interview Transcripts, and Psychometric Questionnaires, a code for Hidden-Markov model statistical analysis, from the tradition of Guennouni and Speekenbrink.

We are grateful to Read Montague and his team at Virginia Tech for his amazing support.
